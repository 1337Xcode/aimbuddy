═══════════════════════════════════════════════════════════════════

Linux/Mac:

→ سيقوم بـ:
  1. تنظيف الصور (حذف الكرار والضبابية)
  2. توجيه البيانات النظيفة للتوسيم اليدوي
  3. فحص جودة التوسيم
  4. تقسيم 70/20/10
  5. إنشاء ملف YAML للتدريب


✏️ STEP 5: ANNOTATE MANUALLY (30-60 MIN)
═══════════════════════════════════════════════════════════════════

استخدم أحد هذه الأدوات:

OPTION A: CVAT (مفتوح المصدر)
─────────────────────────────
🌐 https://cvat.ai
✅ أفضل خيار
✅ دعم كامل للـ YOLO-Pose
✅ تصدير مباشر

OPTION B: Roboflow
──────────────────
🌐 https://roboflow.com
✅ واجهة سهلة جداً
✅ تصدير سريع
❌ نسخة مجانية محدودة

📋 قواعس التوسيم في:
└─ dataset/annotated/annotations/annotation_guidelines.md

📝 ملخص سريع:
├─ وسّم Bounding Box حول الخصم
├─ حدد 5 نقاط مفصلية:
│  0️⃣  Head Center (الأهم!)
│  1️⃣  Left Shoulder
│  2️⃣  Right Shoulder
│  3️⃣  Torso Center
│  4️⃣  Weapon Position
└─ صدّر بصيغة YOLO-Pose

💾 انسخ الملفات إلى:
├─ dataset/annotated/images/       ← الصور
└─ dataset/annotated/labels/       ← ملفات .txt


📊 STEP 6: RUN QA & FINALIZE (2-3 MIN)
═══════════════════════════════════════════════════════════════════

عندما تنتهي من التوسيم:

$ python src/qa_export_agent.py \
    --annotated dataset/annotated \
    --qa-dir qa_reports

$ python src/dataset_splitter.py \
    --annotated dataset/annotated \
    --splits dataset/splits

→ سيُنشئ:
  ✅ dataset/splits/train/    (70%)
  ✅ dataset/splits/val/      (20%)
  ✅ dataset/splits/test/     (10%)
  ✅ dataset/splits/dataset.yaml  ← مهم جداً!


🎓 STEP 7: TRAIN YOUR MODEL
═══════════════════════════════════════════════════════════════════

الآن يمكنك البدء بالتدريب:

$ python src/train.py \
    --data dataset/splits/dataset.yaml \
    --epochs 180 \
    --imgsz 640 \
    --batch 16

أو استخدم السكريبت المعد:
$ scripts/04_train_adaptive.bat
