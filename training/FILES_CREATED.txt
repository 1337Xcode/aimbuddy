🎯 KEY FEATURES:
================================

✅ Automatic Duplicate Detection
   - SSIM-based similarity (> 95%)
   - Saves duplicates for review

✅ Motion Blur Detection
   - Laplacian variance method
   - Configurable threshold
   - Saves blurry images

✅ Image Resizing
   - Maintains aspect ratio
   - Adds black padding
   - Supports 640x640 & 1024x1024

✅ Quality Assurance
   - Random sampling (10%)
   - Comprehensive checks
   - Visual validation (annotated images)

✅ Dataset Splitting
   - Stratified split (70/20/10)
   - Reproducible (seed control)
   - YAML generation for YOLOv8

✅ Comprehensive Reporting
   - JSON reports
   - Error tracking
   - Visual overlays

🚀 QUICK START:
================================

1. Place images:
   training/dataset/raw/screenshots/valorant/
   training/dataset/raw/screenshots/csgo/

2. Run pipeline (Windows):
   cd scripts && 00_annotation_pipeline.bat

3. Run pipeline (Linux):
   cd scripts && bash 00_annotation_pipeline.sh

4. Manual annotation:
   - Use CVAT or Roboflow
   - Place images in dataset/annotated/images/
   - Save labels in dataset/annotated/labels/

5. Verify output:
   - Check dataset/splits/dataset.yaml
   - Review qa_reports/
   - Start training!

🎓 BEST PRACTICES:
================================

1. Quality > Quantity
   - 100 perfect images > 1000 poor images

2. Focus on Head Center
   - Most critical keypoint for aimbot
   - Require pixel-perfect accuracy

3. Consistency is Key
   - Same style across all images
   - Regular guideline review

4. Handle Edge Cases
   - HUD overlap → visibility = 0
   - 80%+ occluded → discard image

5. Validate Often
   - Run QA after each 50 annotations
   - Check problematic_samples/
   - Adjust blur_threshold if needed
